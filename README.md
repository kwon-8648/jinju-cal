# 상품가격계산기 (jinju-cal)

매장관리 웹(gold-cal) 계산기 탭의 **계산 방식을 그대로** 쓰는 PC 전용 계산기입니다. 윈도우와 맥에서 같은 화면·같은 색으로 동작하고, 자료는 **그 PC에만** 저장됩니다.

## 내려받기

[Releases](../../releases) 에서 최신 버전을 받습니다. `main` 에 올리면 테스트만 돌고, 프로그램은 Actions 의 **build → Run workflow** 로 실행할 때만 만들어 올립니다.

- **윈도우**: `jinju-cal-버전-windows.exe` 를 받아 실행합니다. "Windows의 PC 보호" 창이 뜨면 *추가 정보 → 실행*을 누릅니다.
- **맥 (애플 실리콘)**: `jinju-cal-버전-mac.dmg` 를 열고 앱을 *응용 프로그램* 폴더로 끌어 넣습니다. 처음 열 때 "확인할 수 없음" 창이 뜨면 *완료*를 누르고, **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **그래도 열기**를 누릅니다 (새 버전마다 한 번). 1.1.0 이전 dmg 처럼 "손상됨"이라고 나오면 터미널에서 `xattr -cr /Applications/상품가격계산기.app` 을 실행합니다.

## 업데이트 (1.1.1부터)

- 프로그램을 열면 3초 뒤 새 버전이 있는지 확인하고, 있으면 오른쪽 위에 **새 버전 … 업데이트** 버튼이 나옵니다. 화면 맨 아래 **업데이트 확인**으로 직접 확인할 수도 있습니다.
- 누르면 Releases 에서 새 버전을 받아(크기·sha256 확인) 프로그램이 잠깐 닫혔다가 새 버전으로 다시 열립니다. 기준값과 시세는 그대로입니다.
- 프로그램이 직접 받은 파일에는 '인터넷에서 받음' 표시가 붙지 않아서, 맥 '그래도 열기'·윈도우 'PC 보호' 확인은 **처음 설치할 때 한 번만** 하면 됩니다.
- 맥은 앱이 **응용 프로그램** 폴더에 있어야 업데이트됩니다 (내려받은 곳이나 dmg 안에서 열면 옮기라고 안내).
- 윈도우는 처음 받은 exe 파일 자리에서 그대로 바뀝니다 (파일 이름은 처음 받은 이름 그대로).

## 고금 매입 탭 (1.2.0부터)

고금시세계산 v1.16 (`kwon-8648/goldmetal-calculator`) 을 기능 그대로 옮겨 왔습니다. 원래 색(초록·파랑)과 원래 동작을 유지합니다.

- 위쪽 탭 **[상품가격] [고금 매입]**. 고금 매입 안의 19품목 표는 **[금 12품목] [은 7품목]** 탭으로 나눠 저해상도 화면에서도 스크롤 없이 보입니다 (탭 제목에 금·은 합계, 최종합계는 원래대로 전체).
- 금·은·백금 '내가 팔 때' 시세 카드 (직접 입력: Enter 적용 · Esc 취소), 30분 자동 갱신, 직접 입력 후 1~240분 뒤 갱신 확인
- 입고·차감 중량, 환산(돈), 차감금액, 고객매입가, 최종합계 · **저장** → `매입내역.xlsx` 에 누적 (엑셀 저장 설정: 항목·순서·이름·폴더)
- 다른 배율로 비교, 기준품목 이름 설정, Multiplier 설정, 중량 초기화, 글자 크기(10~12pt) — 비교·설정 창의 표도 [금] [은] 탭
- 설정·엑셀은 원래 고금시세계산과 같은 곳을 그대로 이어 씁니다: 설정 `%APPDATA%\OldTownMetalCalculator\last_state.json` (맥 `~/Library/Application Support/OldTownMetalCalculator/`), 엑셀 `문서/고금시세계산/매입내역.xlsx`. 예전 고금시세계산 프로그램과 **동시에 켜지 마세요** (같은 설정 파일을 씀).
- 코드: `jinju_cal/goldmetal/` (core·excel_export·xlsx_append 는 원본 그대로, panel.py 는 원본 app.py 를 탭으로). 원본 검사는 `tests/goldmetal/` 에 그대로 두고 `python tests/test_goldmetal.py` 로 돌립니다.

## 기능

- 한국금거래소 '내가 살 때' 시세 자동 조회 (실행할 때, 10분마다). 직접 조회가 막히면 매장관리 웹의 서울 중계로 다시 조회합니다. 수동 입력도 됩니다.
- 기준값: 부가세율, 10K·14K·18K 함량, 화이트골드 추가금, 판매가 올림 단위 (100원 · 1,000원 · 10,000원)
- 시세는 부가세 별도 가격을 먼저 보여줍니다. 그 아래 **1돈 금액**: 14K·18K 1돈 = 순금 1돈 × 기준값 함량 (부가세 별도를 크게, 포함은 작게). 조회 정보(조회 완료·조회 시각·제공일)는 화면 오른쪽 위 구석.
- **10K·14K·18K 상품**: 중량(g·돈 자동 환산), 공임, 랩다이아 알값, 다이아 셋팅비, 캐럿별 마진 → 금값 · 공임(공임+알값+셋팅비) · 매입원가(부가세 별도) · 최종 판매가(부가세 별도·포함). **화이트 도금**에 체크하면 화이트골드 추가금을 별도·포함 판매가에 그대로 더합니다.
- **순금 상품**: 중량, 고리 금액, 개별공임 → 매입원가(금값 + 고리 + 공임, 부가세 별도) · 최종 판매가(공임 2배, 부가세 별도·포함)
- 검색·코드·상품명·상호·품목·저장·삭제 없이 계산만 합니다 (1.1.0부터).
- 화면 오른쪽 아래에 버전이 표시됩니다. 그 옆 **화면 크기**(100·90·80·70%)로 글자와 칸을 함께 줄일 수 있습니다 (이 컴퓨터에만 저장, 다시 열면 적용). 계산 설명은 각 제목 옆 ⓘ 에 마우스를 올리면 보입니다.

## 계산식 (매장관리 웹과 같음)

- 금값 = 시세 ÷ (1 + 부가세) × 중량/3.75 × 함량
- 매입원가 = 금값 + 공임 + 알값 + 셋팅비 (부가세 별도)
- 최종 판매가 · 부가세 포함 = 올림(매입원가 × (1 + 부가세) ÷ (1 − 마진)) + 화이트 추가금
- 최종 판매가 · 부가세 별도 = 올림(매입원가 ÷ (1 − 마진)) + 화이트 추가금
- 순금: G = 시세 ÷ (1 + 부가세) × 중량/3.75 + 고리 · 매입원가 = G + 공임 · 최종 판매가(공임 2배) = 올림(G + 공임×3), 부가세 포함 = 올림((G + 공임×3) × (1 + 부가세))

`tests/test_core.py` 가 웹판 원본 계산 코드(`tests/web_reference.js`)와 무작위 입력 2만 건을 대조해 1원까지 같은지 확인합니다.

## 개발

```
pip install -r requirements.txt
python run.py                 # 실행
python tests/test_core.py     # 웹판과 계산 대조 (node 필요)
python tests/test_ui.py       # 화면·시세 조회 동작
python tests/test_goldmetal.py  # 고금 매입 (고금시세계산 원본 검사)
python tests/test_update.py   # 업데이트 확인·받기·바꿔치기 (빌드 때는 실제 맥·윈도우에서 tests/test_update_ci.py 도)
pyinstaller --noconfirm jinju-cal.spec   # 빌드
```

새 버전을 낼 때는 `jinju_cal/__init__.py` 의 `__version__` 을 올리고 `main` 에 올린 뒤, Actions 에서 build 를 실행합니다.
